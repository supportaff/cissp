# CISSP Prep by Prakash

Premium CISSP preparation landing page built with Next.js, TypeScript, Tailwind CSS, React, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Configure production URLs

Set `NEXT_PUBLIC_SITE_URL` to the real canonical site URL before deployment.

## Stripe

The landing page contains a clearly marked Stripe Checkout placeholder. Replace the placeholder link with a Stripe Payment Link or route to your own secure Checkout Session endpoint. Never put Stripe secret keys in client-side code.

## Before launch

- Replace the professional portrait placeholder.
- Add the real LinkedIn URL and any verified professional biography/certifications.
- Replace the generic contact email.
- Finalize exact refund eligibility requirements, timing windows, required documentation, and any completion criteria.
- Replace the starter Terms and Privacy pages with your final legal terms, reviewed for your jurisdiction and actual data/payment workflows.
- Set `NEXT_PUBLIC_SITE_URL`.
- Connect the $99 checkout flow.
